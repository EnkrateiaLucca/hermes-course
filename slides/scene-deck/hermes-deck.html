Four things that break it

1 · context too smallHermes refuses to start below 64K.→ -c 65536 · Ollama: OLLAMA_CONTEXT_LENGTH
2 · no tool callsThe model writes text instead of calling tools.→ --jinja · vLLM: --tool-call-parser
3 · endpoint 404The base URL is missing /v1.→ http://localhost:8080/v1
4 · wrong modelPicking a “Hermes 4” model for Hermes.Nous Hermes 3/4 are chat models, not agentic. Use Qwen, Gemma, GLM or gpt-oss.
